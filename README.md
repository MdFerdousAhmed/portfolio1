##  Installation

Clone the repository

```bash
git clone https://github.com/MdFerdousAhmed/portfolio1.git
```

Go to the project directory

```bash
cd portfolio
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```
